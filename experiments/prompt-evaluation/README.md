# Prompt evaluation

Compare prompt variants on the same or closely matched task.

Record:
- Task and acceptance criteria.
- Prompt version and context available.
- Output quality against a predefined rubric.
- Tests and defects.
- Usage metrics if available.
- Human correction and rework.
- Run count and known confounders.

Do not conclude that a prompt is better solely because its answer is longer, sounds more confident, or uses fewer words.
