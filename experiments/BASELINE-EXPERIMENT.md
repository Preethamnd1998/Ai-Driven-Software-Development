# Baseline Experiment — First Vertical Slice

## Objective
Establish a baseline before introducing prompt/context optimizations, hooks, RAG, embeddings, knowledge graphs, or MCP integrations.

## Task
Implement one small vertical slice from an approved requirement. Choose the first slice after requirements are reviewed.

## Record before starting
- Date and commit SHA.
- Agent/tool and exact plan/model setting where known.
- Subscription reference and current limits checked.
- Task description and acceptance criteria.
- Context files/instructions supplied.
- Starting repository state and test baseline.

## Record during and after
- Developer active time and elapsed time, separately.
- Available token/usage metrics from the tool (or `Not available`).
- Tool calls, file searches/reads and retries where observable.
- Files changed and diff size.
- Commands and tests actually run.
- Test results, review findings, defects, rework and unresolved risks.
- Additional service or infrastructure costs.

## Result
- What worked?
- What failed?
- What required human correction?
- Did the acceptance criteria pass?
- What should be changed for the next run?

## Comparison rules
Change one major variable at a time when possible. Use comparable tasks and the same quality criteria. Do not generalize from one run. Preserve raw evidence and state limitations.
