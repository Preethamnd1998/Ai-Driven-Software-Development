# Context management

Document the context sources used by the agent, such as repository instructions, architecture notes, domain glossary, task brief, and relevant file excerpts.

For each experiment, record:
- Which context sources were available.
- Which files/tools were actually consulted, when observable.
- What was omitted and why.
- Whether the agent made incorrect assumptions.
- Repeated exploration, retries, and verification outcomes.

Do not claim token savings unless token usage is exposed and recorded. File counts and tool calls are useful proxies but are not token counts.
