# Prompt library

Store reusable prompts with:
- Purpose and intended task.
- Required inputs and assumptions.
- Expected output format.
- Constraints and safety rules.
- Verification checklist.
- Version/date and change notes.
- Example run and result reference, where shareable.

Keep prompts tool-agnostic where practical. Put tool-specific features in clearly labelled variants. Never commit API keys, personal data, employer code, or private agent configuration.
