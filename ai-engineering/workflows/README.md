# AI engineering workflows

Document repeatable workflows such as:
1. Understand the task and acceptance criteria.
2. Inspect only relevant repository context.
3. Produce a plan and list assumptions.
4. Implement a bounded change.
5. Inspect the diff.
6. Run targeted tests, then appropriate regression tests.
7. Report files changed, commands executed, results, and remaining risks.

Treat the workflow as a proposal until tested against the selected coding agent and repository.
