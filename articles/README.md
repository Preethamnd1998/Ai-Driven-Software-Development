# Article drafts

The article series is defined in `../ROADMAP.md`. Add an article draft only when its supporting artifacts are ready for review.

Each article should contain:
1. The engineering question.
2. Context and constraints.
3. Method and exact reproducible steps.
4. Evidence and results.
5. Failures and limitations.
6. Reusable takeaways.
7. Links to GitHub artifacts and relevant commits.
